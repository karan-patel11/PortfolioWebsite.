# Design Inspiration & Guidelines

* **Reference Site:** https://khanhnguyen.design/
* **Role:** Modern Product/Developer Portfolio Redesign

---

## Visual Identity & Aesthetics
* **Theme:** Minimalist, editorial dark/neutral canvas (deep charcoal/matte black `#1e1e1e` or soft warm off-white, high contrast text).
* **Typography:** Bold typographic hierarchy. Distinct display titles paired with clean, readable sans-serif body text (e.g., Inter, Geist, or Plus Jakarta Sans).
* **Grid & Spacing:** Generous whitespace, clean horizontal separators (`1px` subtle borders), and strict alignment.

## Key UI Elements to Adapt
1. **Hero Section:**
   * Bold personal statement/intro line (concise, high-impact typography).
   * Subtle status badge (e.g., "Available for work" / location / local time).
2. **Project Showcase:**
   * High-contrast project cards or clean editorial list rows.
   * Prominent tag metadata (year, stack, role).
   * Clean hover states with smooth micro-interactions.
3. **Experience & Services:**
   * Structured, tabular timeline with clean divider borders.
   * Monospaced/accented indices or bullet symbols (e.g., `(A)`, `(B)` or `✺`).
4. **Navigation & Footer:**
   * Sticky, minimalist top bar with smooth anchor links.
   * Clear call-to-action (CTA) section for contact/email.

## Implementation Rules
* Retain all personal details, work history, links, and content from the existing portfolio.
* Apply smooth CSS transitions and modern spacing without cluttering the layout.
* Keep the code clean, responsive, and performant.
